## 1. 公共API接口清单

### 1.1 设备管理接口 (game_device.h)

| 函数签名 | 参数 | 返回值 | 功能说明 |
|---------|------|--------|---------|
| `OH_GameDevice_GetAllDeviceInfos` | allDeviceInfos: 输出设备列表 | 错误码 | 获取所有在线设备信息 |
| `OH_GameDevice_RegisterDeviceMonitor` | deviceMonitorCallback: 回调函数 | 错误码 | 注册设备监听器 |
| `OH_GameDevice_UnregisterDeviceMonitor` | 无 | 错误码 | 注销设备监听器 |
| `OH_GameDevice_DestroyAllDeviceInfos` | allDeviceInfos: 设备列表 | 错误码 | 销毁设备信息实例 |
| `OH_GameDevice_AllDeviceInfos_GetCount` | allDeviceInfos, count | 错误码 | 获取设备数量 |
| `OH_GameDevice_AllDeviceInfos_GetDeviceInfo` | allDeviceInfos, index, deviceInfo | 错误码 | 获取指定索引的设备信息 |

## 2. InnerAPI接口清单

**权限说明**: InnerAPI接口仅限系统服务调用

| 接口名称 | 权限控制 | 功能说明 |
|---------|---------|---------|
| `IdentifyDevice` | 无特殊权限 | 执行设备识别 |
| `SyncIdentifiedDeviceInfos` | 无特殊权限 | 同步已识别设备信息 |
| `SyncSupportKeyMappingGames` | **仅系统服务** | 同步支持键位映射的游戏 |
| `GetGameKeyMappingConfig` | 无特殊权限 | 获取游戏键位映射配置 |
| `SetCustomGameKeyMappingConfig` | **仅系统服务** | 设置自定义游戏键位映射配置 |
| `SetDefaultGameKeyMappingConfig` | **仅系统服务** | 设置默认游戏键位映射配置 |
| `BroadcastDeviceInfo` | 无特殊权限 | 广播设备信息 |
| `BroadcastOpenTemplateConfig` | 无特殊权限 | 广播打开模板配置页面 |
| `EnableGameKeyMapping` | 无特殊权限 | 为支持键位映射的游戏启用输入转触摸 |

## 3. 核心数据结构定义

### 3.1 设备信息结构

```cpp
struct DeviceInfo : public Parcelable {
    std::string uniq;                    // 设备唯一标识
    std::string name;                    // 设备名称
    int32_t product = 0;                 // 产品ID
    int32_t vendor = 0;                  // 厂商ID
    int32_t version = 0;                 // 版本号
    std::string phys;                    // 物理地址
    DeviceTypeEnum deviceType = UNKNOWN; // 设备类型
    std::unordered_set<int32_t> ids;     // ID集合
    std::unordered_set<InputSourceTypeEnum> sourceTypeSet; // 输入源类型集合
    int64_t onlineTime = 0;              // 上线时间
    int32_t status = 0;                  // 状态(0-在线,1-离线)
    std::string vidPid;                  // 厂商_产品ID
    bool hasFullKeyBoard = false;        // 是否有完整键盘
};
```

### 3.2 游戏信息结构

```cpp
struct GameInfo : public Parcelable {
    std::string bundleName;              // 包名

    std::vector<int32_t> supportedDeviceTypes; // 支持的设备类型
    int32_t windowId = 0;                // 窗口ID
};
```

struct KeyToTouchMappingInfo : public Parcelable {

## 4. 接口调用示例流程

### 4.1 设备监控流程

```
1. 应用启动
   ↓
2. 注册设备监听器
   OH_GameDevice_RegisterDeviceMonitor(callback)
   ↓
3. 设备事件触发
   → callback(GameDevice_DeviceEvent*)
   ↓
4. 获取事件类型
   OH_GameDevice_DeviceEvent_GetChangedType(event, &type)
   ↓
5. 获取设备信息
   OH_GameDevice_DeviceEvent_GetDeviceInfo(event, &deviceInfo)
   ↓
6. 获取设备详情
   OH_GameDevice_DeviceInfo_GetDeviceId(deviceInfo, &deviceId)
   OH_GameDevice_DeviceInfo_GetName(deviceInfo, &name)
   ↓
7. 销毁资源
   OH_GameDevice_DestroyDeviceInfo(&deviceInfo)
   ↓
8. 应用退出时注销监听器
   OH_GameDevice_UnregisterDeviceMonitor()
```

### 4.2 游戏手柄按钮监控流程

```
1. 游戏启动
   ↓
2. 注册按钮监听器
   OH_GamePad_ButtonA_RegisterButtonInputMonitor(callback)
   OH_GamePad_LeftThumbstick_RegisterAxisInputMonitor(callback)
   ↓
3. 按钮事件触发
   → callback(GamePad_ButtonEvent*)
   ↓
4. 获取事件详情
   OH_GamePad_ButtonEvent_GetDeviceId(event, &deviceId)
   OH_GamePad_ButtonEvent_GetButtonAction(event, &actionType)
   OH_GamePad_ButtonEvent_GetButtonCode(event, &code)
   ↓
5. 游戏退出时注销监听器
   OH_GamePad_ButtonA_UnregisterButtonInputMonitor()
```

### 4.3 InnerAPI调用流程 (系统服务)

```
1. 系统服务启动
   ↓
2. 获取GameControllerServerClient实例
   GameControllerServerClient::GetInstance()
   ↓
3. 同步支持键位映射的游戏
   SyncSupportKeyMappingGames(true, gameInfos)
   ↓
4. 设备连接时识别设备
   IdentifyDevice(deviceInfos, identifyResult)
   ↓
5. 同步已识别设备信息
   SyncIdentifiedDeviceInfos(identifiedDeviceInfos)
   ↓
6. 游戏启动时获取键位映射
   GetGameKeyMappingConfig(param, gameKeyMappingInfo)
```
