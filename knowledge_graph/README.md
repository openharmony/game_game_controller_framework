### 核心特性一览

| 特性 | 说明 |
|------|------|
| **设备监听** | 监听游戏外设上下线事件，获取设备信息 |
| **输入监听** | 监听手柄按键、摇杆、扳机等输入事件 |
| **输入转触控** | 17种映射类型，将外设输入转为触摸屏事件 |
| **设备识别** | 自动识别键盘、手柄、鼠标等设备类型 |
| **配置管理** | JSON配置驱动，支持默认+自定义配置 |

### 技术亮点

1. **三层架构**：接口层、框架层、服务层职责清晰
2. **17种Handler**：支持多种输入转触控场景
3. **异步处理**：使用ffrt队列避免阻塞主线程
4. **高性能**：O(1)复杂度快速过滤机制
5. **线程安全**：多层次锁保护共享数据
6. **按需加载**：SA非常驻进程，按需拉起

## 核心概念速查

### 组件关系图

```
应用层
  │
  ├─→ GameDevice API (设备管理)
  │     └─→ GameDeviceClient
  │
  └─→ GamePad API (手柄控制)
        └─→ InputEventClient
              │
              └─→ WindowInputIntercept (事件拦截)
                    │
                    ├─→ KeyToTouchManager (转触控)
                    │     └─→ 17种Handler
                    │
                    └─→ GameControllerServerClient (IPC)
                          │
                          └─→ GameControllerServerAbility (SA服务)
                                │
                                ├─→ DeviceManager (设备管理)
                                └─→ KeyMappingManager (配置管理)
```

### 数据流简图

```
设备上线 → 设备识别 → 配置加载 → 事件拦截 → 输入转触控 → 游戏响应
```
